# 📝 Create Account — Registration Form

Projeto de desenvolvimento Front-End de uma interface de criação de conta, com design moderno, minimalista e responsivo.

O objetivo é praticar a construção de formulários utilizando HTML5 e CSS3, trabalhando organização, alinhamento e adaptação para diferentes tamanhos de tela.

## ✨ Funcionalidades

- Formulário de criação de conta.
- Campos para nome, e-mail, senha e confirmação de senha.
- Checkbox para aceite dos termos.
- Botão de criação de conta.
- Link para acesso à tela de login.
- Layout responsivo para tablets e celulares.
- Efeitos de foco nos campos e interação no botão.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 📚 Conceitos praticados

- Estruturação semântica com HTML.
- Formulários e elementos de entrada.
- Flexbox.
- Box Model.
- Gradientes lineares.
- Box Shadow.
- Pseudo-classes (`:focus`, `:hover` e `:active`).
- Transições com CSS.
- Media Queries.
- Responsividade.

## 🎯 Objetivo

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento Front-End, com foco no aperfeiçoamento de HTML e CSS e na construção de interfaces web modernas e responsivas.

## ⚠️ Observação

Esta é uma interface demonstrativa para fins de estudo. Não possui sistema de autenticação, Back-End ou armazenamento de dados.
